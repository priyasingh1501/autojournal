Place your app icon and splash screen assets here.

Required files (referenced in app.json):
- icon.png          (1024x1024 px, PNG)
- splash.png        (1284x2778 px or similar, PNG)
- adaptive-icon.png (1024x1024 px, PNG, Android foreground)

You can generate placeholder assets using:
  npx expo install expo-splash-screen
  npx expo-splash-screen --background-color "#1a1a2e"

Or use any image editor to create simple placeholder icons while developing.
The app will work without these for local development via Expo Go,
but you will see warnings in the console.
